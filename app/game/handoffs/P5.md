## Scene contract (how other pieces plug in)
- Register: create `src/scenes/<name>/index.ts` that calls `registerScene('<name>', () => new MyScene())` from `src/app/registry.ts`. `src/main.ts` eagerly imports every `src/scenes/*/index.ts` (Vite glob); a real scene always replaces the placeholder of the same name (`_placeholders.ts`, registered with `{ placeholder: true }`).
- `SceneContext` (src/app/scene.ts, additive): `ctx`, `ui` (a per-scene root div inside #ui, removed on exit), `goto(name, data?, { transition: 'fade'|'cut'|'black', duration })`, `fast`, `audio` (AudioEngine, always safe), `params`. A scene that is leaving cannot redirect the flow (its goto is ignored once a transition is pending).
- Music: the app calls `audio.setScene(<scene name>)` on every switch (title → silence).
- Data per scene:
  - `title`: none. Starts `preloadMine()` (src/app/worlds.ts → `preloadMineRenderer(1)`), so later `getMineRenderer()` never pays a full synchronous bake.
  - `cutscene`: `{ session }` (new Session, phase `bonus`). Must end with `goto('bonus', { session, world: { renderer, camera, view } })`.
  - `bonus`: `{ session, world? }`. Chooses via `session.dispatch({type:'chooseBonus', bonus})`, then `goto('whisper', { session, world })` (pass `world` through; the placeholder does).
  - `whisper`: `{ session, world?: { renderer, camera, view? }, continued?, direct? }`. With `world` it reuses that renderer + camera exactly (no re-bake, no fog settle, no fit/snap; bounds/zoneBounds only filled in if missing; clamping applies only on later player input), continues the world clock from `view.time`, and fades the HUD in over the unchanged frame; people then walk to their posts. Use transition `cut` for every hand-over hop (the placeholder bonus does). Without it: `getMineRenderer()` (shared, art seed 1) + `whisperStartCamera()` (src/app/worlds.ts; same framing as dev/mine.html?preset=start).
  - `watershed`: `{ session, camera: { x, y, scale } }` (the whisper camera at the moment of leaving; renderer = `getMineRenderer()`), entered with transition `cut`.
  - `shade`, `ending`: `{ session }`. `defeat`: `{ session }`.
  - Direct jumps via `?scene=<name>` pass `{ session, direct: true }` with a bonus already chosen (except cutscene/bonus).
- Session (src/app/session.ts): `dispatch(action)` → `{ok, events}|{ok:false, reason}`; `subscribe(fn(events, state, action))`; `log` (seed + actions = replay); autosave to localStorage `hg.save.v1`; `Session.load()`, `sceneForSession(s)`.
- UI kit (src/ui/index.ts): `installTheme()` (done by main), `h`, `u(n)` = calc(var(--u)*n), `place`, `button` (disabled-with-reason), `iconButton`, `gauge`, `pips`, `tickNumber`, `modal`, `banner`, `toast`, `tip(el, content|fn)` rich tooltips (title/value/body/rows/total/formula/warn/foot), `icon(name)` inline SVG (resources, factions, every order and miracle), classes `.hg-panel[.soft|.violet|.gold|.danger]`, `.hg-card[.evil]`, `.hg-tag`, `.hg-kbd`, `.hg-label`, `.hg-h1/h2/h3`, `.hg-num`. `uiConfig.sound/denied` are wired by main.ts.
- Debug: `window.__hg` = { session, state(), seed, goto, advance(ms), act, legal, endTurn, scene, newSession, hooks, app, sim, Session }. Whisper hooks: `__hg.hooks.whisper` = { personScreen(id), zoneScreen(id), select(id), selectZone(id), mode(), camera, renderer, settle(), frameAll(), hints }.
