(4) **The rite** ("The Naming", Temple, ≥ 40): the High Priest names one follower for the fire; lying low does not hide them. (5) **The ward** (Temple, ≥ 25): priests ward one of your areas for 5 Days (colour pushed back). (6) **The burning** (Public, ≥ 50): a mob burns the building of a facility you hold (or your strongest area): Hold −40, its facility lost for 8 Days. (7) Answers: hide (the levied lie low), items made at the facilities (false weights, a profaned relic, a black draught), an Elite's favour, the three new acts of evil, or cooling the track below the floor before Dusk. # v3.2 CHANGES — Night → Day → Dusk, homes above ground, the LIVING bridge (spec §3, §5; DECISIONS §16) — READ FIRST

Binding and **additive** for readers: every v3.1 field, action and event stays; only the moments (`time`) of a few events move and three event fields are added. Status lines at its end.

**The turn (one call, `endNight` / `endTurn`):** Night (the player acts; `state.clock === 'night'` between steps) → **the Day** (`time` 0–0.9: bell, commute, shift, carts, stain, heat, story, evening walk home) → **Dusk** (`time` 0.9–1.0: tithe, vault, **the offering** with tribute, **the count**, searches, facilities, items, prayer results, the gate, then `dusk` + `dealt` at 1.0) → the next Night.
- Every event returned by `endNight` now carries `time` (0–1) **and** `phase: 'day' | 'dusk'`, and the array is **stably sorted by `time`** (LIVING's notes are merged in by time).
- `StepResult.day?: DayFilm` (only on `endNight`): `{ turn, events: GameEvent[] /* phase 'day', by time */, dusk: GameEvent[] /* phase 'dusk', by time */, calendar: CalendarDay | null, weather: DayWeather | null, plan: DayPlan | null /* LIVING's plan: stops for staging, BEHAV */ }`.

**Homes above ground:** every person's `Unit.home` is a surface (town-region) zone — miners live in the Miners' Rows (`slagrows`), at the pit head (`minehead`) or the High Warrens, taken from LIVING's households when the society exists (fallback: day workers 70 % `slagrows`, guards / overseers `minehead`). Nobody's home is a mine zone (bunks are a mess hall now). Night shift sleeps at home by day.
- A follower stains their home area every day (their night half is at home: the usual Hold rules).
- **Move** may target a surface place (any town zone you can see, not `citygate`): the follower's work becomes that place (no digging there; they stain it by day). Mine ↔ town moves count as far (2 AP).
- **Reach** (`inReach(s, unit)`, used by `whisperWhy` and `whisperTargets(s)`): a person is in reach if their night spot is reachable (as before), **or** they work at a reachable mine face/area (you speak through the stone they worked all day), **or** they share a household with a follower, have a tie (kin, friend, lover) to one, or sleep next door to one (the same home place). In the Whisper stage a town zone is no longer reachable merely because a follower sleeps there (that would put the whole Rows in reach); it is when it is coloured.

**LIVING bridge (`src/sim/livingBridge.ts`, SIM's):** `state.society` (LIVING `Society`, created once at `createGame`; treated as immutable and shared between clones) and `state.living: LivingToday | null` (today's folded hooks; kept through the following night for whisper odds). Once per Day: `planDay(society, turn − 1, facts)`; `society = plan.next`. Folded into the rules: strike × per face, crew × per zone (diggers who do not come in), guards + per zone (search odds, stain push), search × per zone, count tolerance ×, whisper odds + per person and per zone (the next night), reach + (wind), lift stop (the shift is cut short), Suspicion + and notice × (today's gains), Hold × per zone. `livingHooks(s)` returns the folded numbers with their plain whys for the HUD. If LIVING throws, the Day runs without it (`state.living.error` set).

**Migration — PLAY-CORE:** read `StepResult.day` (or sort by `time` yourself — the array is already sorted); stage the film from `day.events` + `day.plan` and the dusk ledger from `day.dusk`; the hand is dealt after the offering and the count. **FEEL:** the count and the searches are now Dusk beats (0.96 / 0.97) after the stones are set down; render `living` notes from `note.text` / `note.textKey`. **BEHAV:** `u.home` is always a town zone; read LIVING's stops from `day.plan.plans[unitId]` (adopted ids are the sim's); the lift carries every miner both ways.

## Actions
```ts
type Action =
  | { type: 'chooseBlessing'; blessing: BlessingId }      // start (phase 'bonus') and at each level-up (state.blessingOffer)
  | { type: 'chooseBonus'; bonus: BlessingId }            // alias (accepted, never offered)
  | { type: 'resolveEvent'; option: number }
  | { type: 'whisper'; target: UnitId }                   // 1 AP + Nether (spec Influence cost); alias { type: 'influence' }
  | { type: 'setRoutine'; unit: UnitId; routine: RoutineId }   // 1 AP; follower only; must differ
  | { type: 'move'; unit: UnitId; zone: ZoneId }          // 1 AP (2 if far); a chance (movePreview); success → unit.work = zone
  | { type: 'playMiracle'; card: MiracleId; pay: CrystalId[]; target?: UnitId | ZoneId }   // one a night; pay ≥ cost in value, burnt
  | { type: 'playEvil'; card: EvilId; target?: UnitId | ZoneId }   // one a night; devour = playEvil { card: 'devour', target }
  | { type: 'skipHand'; hand: Hand }                      // discard tonight's hand unplayed (free)
  | { type: 'reroll'; hand: Hand }                        // needs god.rerolls > 0 (Loaded / Second Chance)
  | { type: 'eat'; crystal: CrystalId }                   // free; Hunger −= value × BALANCE.hungerPerValue
  | { type: 'setCrystal'; crystal: CrystalId; socket: number }   // free; cut crystals only; socket 0..sockets-1, empty
  | { type: 'unsetCrystal'; crystal: CrystalId }          // free; back to the inventory
  | { type: 'cut'; crystal: CrystalId }                   // costs Nether (cutCost by tier); rough only → state.pendingCut
  | { type: 'chooseCut'; crystal: CrystalId; index: number }   // must follow `cut`; resolves crack / flaw
  | { type: 'graft'; from: CrystalId; onto: CrystalId; line?: StatLineId; effect?: boolean }  // free; donor destroyed
  | { type: 'endNight' } | { type: 'endTurn' };           // endTurn = alias
```

## Rules in one line (numbers: DECISIONS `### SIM-v3 — The mining loop`)
- Every unit whose work area is a rock face and who is on shift makes `strikeRolls` rolls at `strikeChance × face × (1 + strength bonus)`; rarity from one table (52/27/13/5.5/2/0.5 %), bent only by `strikeLuck` (chance to roll twice and keep the better).
- Non-followers' finds → the area's cart → the lift → the Tally. Followers pocket theirs (`stash`), except on `lieLow` (handed in).
- Pray: Faith (spec formula over praying followers) → Nether; Hold where they are; stash grows. Offer: at dusk, walks the stash to the grave (`offered`, one event per crystal); no Faith that night; guards on the way may spot them. Lie low: no Faith, no stash, cools heat, never searched.
- Tally: expected = Council's estimate (diggers on shift × `tallyPerDigger`); short = expected − counted; heat on the Council only for the part above tolerance (`tallyTolerance` × expected + `tallyFloor`); a run of short days raises search odds; searches at the lift take stashes (caught +1; 2 → taken).
- Cards: 3 miracles + 3 acts of evil dealt each Dusk from pools that widen with Divinity; one of each per night; miracles cost crystal value (paid by burning chosen crystals; overpay is lost); acts sate Malice, raise heat; devour feeds Hunger and frees the soul as a rough crystal.
- Followers' own evil: each Day chance `malice / 200` (max 0.4); Malice falls by half the act's value; heat as normal.
- AP: refilled each night to apMax.
- Crystals: eat (Hunger −value×5), burn, set (lines + effect apply while set), cut (Nether; 2–3 spreads; crack 8 % → a tier down; flaw 10 % → an odd effect from the flaw list), graft (one line or the effect, donor destroyed, capped).
- Blessings: 1 of 3 (4 with Second Sight) at the start and each level-up.
- Watershed: Divinity IV and the pit head rooted (v2 rule). Town: groups and Elites handle crystals; the tally hall's vault holds a guaranteed Impossible crystal (a follower Elite or the hall rooted opens it); the gate ending (Divinity VII and the town gate rooted → `won`).

## v2 API contract (exact)

### Turn = Night (player acts) → Day (resolution, replayed)
- `createGame(seed, opts?)`, `legalActions(s)`, `applyAction(s, a)`, `endNight(s)` (= `endTurn(s)`, same result) → `{ state, events }`.
- During Night every unit stands at its **night position** `unit.at` (=`unit.zone`). `endNight` resolves the Day and returns the next Night.
- Events returned by `endNight` are **ordered** and every event carries `time` (0–1) for the replay:
  0.00 `bell` · 0.05–0.30 morning commute (`moved`, `liftRide`) · 0.35–0.55 work (`taskResult`, `discovered`, `enemyMoved`) ·
  0.60–0.75 the stain (`holdChanged`, `rooted`, `receded`) · 0.80 heat/pushback (`heat`, `factionAction`, hunters…) ·
  0.85–0.95 evening commute back to night positions (`moved`, `liftRide`) · 1.00 next Dusk (`dusk`, `levelUp`, `stageAdvanced`, `won`, `defeat`).
  Events produced by `applyAction` have `time` absent.

### Actions (`Action`)
