## Successor 4 (2026-11-23, from 10:50) — API additions (additive; exact names) and requests
- **`audio.seekScene?(seconds: number, opts?: { fadeSeconds?: number })`** — the cutscene's skip: the current bed's
  own timeline jumps to `seconds` after its start (default fade 0.4 s, equal-power crossfade, click-free); every
  layer still sounding there is continuous and lands on its value at that time; cue sounds still ringing fade too.
- **`audio.debugMix?()`** (dev / e2e; `?audiotap=1` adds the analyser): `{ t, scene, phase, levels, view, rmsDb }`.
- **REQUEST → P7 (cutscene, `src/scenes/cutscene/index.ts` `skip()`):** right after `this.skipTo = …` add
  `this.safeAudio((a) => a.seekScene?.(this.skipTo, { fadeSeconds: 0.4 }));` — without it a skip keeps the score
  running at real time for ~1.1 s and then the app crossfades to the bonus bed over 1.6 s (a skip at 3 s would
  hand over from the memory's chord, not from the end drone). Optional: drop the cues `flame-rises`
  (thresholdAlarm) and `colossus-shatters` (purge) — the bed now carries the gold swell and the break at exactly
  those points (the engine no longer lets cue sounds duck the opening's score, so they are harmless if kept).
- The opening bed (`beds/scenes.ts cutsceneBed`) reads every time from `CUE_POINTS`; it ends on `BONUS_GROUND`
  (drone + rumble + the god's thread), which is exactly what the bonus bed opens with.
- The quiet night: gameplay beds' core −3 dB at night (`NIGHT_GAIN_DB`), cards / hand / UI −3…−4 dB and the
  whisper −4 dB and drier at night over a gameplay bed (`NIGHT_SOFT_DB` in core.ts); failures, devour, tier ≥ 3 full.
- The world's beds: a big level step (≥ 0.15) glides with τ ≥ 1.5 s (`viewTau`), the first view after a scene
  change with τ 1.6 s.
- The Temple's hum is a held, slurring chord (`ambience.ts startHymn`); braziers and bowls stay events.

## Theme round (successor 3, 2026-11-23) — API additions (additive; exact names; published before implementing)
- **`audio.setView?(view: AudioView)`** — the one call the play scene makes (every frame or at 4 Hz; cheap, only changes
  are applied). The engine derives every ambience bed from it, glides them, and sets Night/Day itself.
  ```ts
  interface AudioView {
    place: 'mine' | 'town' | 'valley' | 'grave';   // what the camera shows (grave = the deepest reach, close)
    zoom?: number;            // 0 close … 1 far (far = less detail: fewer clicks and steps, more wind / wash)
    phase?: 'night' | 'day' | 'dusk';              // FEEL's DayClock.phase (null clock → 'night')
    time?: number;            // DayClock.t 0 dawn … 1 dusk (market busiest midday, tavern in the evening)
    speed?: number;           // DayClock.rate (×1 / ×2 / ×4; fades and glides are scaled by it)
    weather?: { kind: string; strength?: number }; // WEATHER kinds: clear overcast drizzle rain storm fog wind colddawn
    near?: Partial<Record<'lift' | 'carts' | 'water' | 'smelter' | 'market' | 'tavern' | 'temple' | 'council' |
                          'road' | 'beasts' | 'crowd', number>>;   // 0..1 how close / on screen each source is
    liftMoving?: number;      // 0..1 the cage is moving
    holy?: boolean;           // the Flame's day: the Temple's hum is heard across the town
    mood?: CrowdMood;         // the town's mood now (see setMood)
    nether?: number;          // 0..1 the god's Nether, normalised by the caller (e.g. log10 scale) — the grave's voice
  }
  ```
  Explicit `setAmbience` calls still work and are merged on top (the offering's `procession` / `grave` stay the scene's).
- **Weather (orchestrator, 08:50):** `audio.setWeather?.(weather.state.audio)` each frame (`{ rain, wind, drips }`,
  0..1; only changes are applied) — merged into the view's beds (town: rain on roofs + mud, wind, fewer voices in
  the lanes and a fuller tavern; mine: drips → `seep`, a little rain down the shaft). `weather.onThunder(e =>
  audio.thunder?.(e.strength, e.delay))` — the engine schedules the sound `delay` s later: `thunderNear` (a crack)
  when delay ≤ 0.3 s, else `thunderFar` (a roll), louder with strength. `AudioView.weatherAudio` is the same input
  for a single call.
- **New ambience kinds** (`AMBIENCE_KINDS`): `beasts` (pit-beast lowing, shell scrape, skitter chitter) · `crowd`
  (wickfolk crowd: clicks, trills, hums, in the current mood) · `council` (cold shard-lamp hum, iron, stamping, a far
  struck plate) · `lamps` (the shard-lamps' thin hum in the mine) · `nether` (the grave's own voice: a sub-bass presence
  that grows with the level). `dogs` is removed from the list (theme §9); a `dogs` key is still accepted and plays
  `beasts`. Re-voiced: `market` and `tavern` (wickfolk voices, clay chits and cups, a shell-lyre), `hymn` (the Temple:
  low hummed chords, brazier roar, brass bowls), `road` (a pit-beast train), `night` (near silence: far drips, the
  eaves, a skitter, a moth; no crickets or owls).
- **`audio.setMood?(mood: 'calm' | 'uneasy' | 'fervent' | 'afraid')`** — the wickfolk voice's mood for `crowd`,
  `market`, `tavern` (glided over a few seconds; default calm).
- **`VolumeKind` += `'ambience'`** — `setVolume('ambience', 0..1)` / `getVolume('ambience')`; ambience now has its own
  bus (still ducked under heavy notes with the music). Settings: please add an Ambience slider (request to HUD / app).
- **New sfx:** `councilPlate` (2; the Council's struck-plate signal) · `wickCall` (1; one wickfolk utterance; `pitch`
  = the speaker) · `wickLaugh` (1; a rising trill) · `wickGrief` (2; a long low hum taken up by others) · `beastLow`

### Beds, phase, ambience, stingers
- `audio.setScene(scene, { fadeSeconds })` — scenes: silence, cutscene, bonus, whisper, watershed, shade, ending, defeat.
- `audio.setPhase?.('night' | 'day', { fadeSeconds? })` — `'day'` when the Day film starts (with `sfx('dawnBell')`),
  `'night'` when it ends (with `sfx('duskBell')`). Night = close and hushed; Day = the bed opens (brighter layer,
  distant picks, carts, the lift wheel). Crossfaded (default 1.5 s in, 2 s out), click-free. Default phase: night.
- `audio.setAmbience?.({ lift, carts, water, smelter, market, wind, procession, grave })` — each 0..1 (omitted keys keep
  their value), smoothed; gate by what is on screen / zoom. Ambience sits under the music bed.
- `audio.stinger?.(name)` → seconds (0 if not played); `STINGER_NAMES = ['watershedBloom', 'cityAnswer', 'shadeTop', 'bestFind']`.
- `BED_CUES.watershed` / `BED_CUES.ending`: seconds after `setScene` at which the music's beats land
  (watershed: rise 0, wind 9, bloom 11.5, motif 12.2, settle 24; ending: motif 1.5, cityAnswer 14, open 22).
- `audio.setIntensity(0..1)`, `audio.setHunger(0..1)` each Dawn; `setVolume / getVolume / setMuted / isMuted /
  suspend / resume / setSeed?(runSeed) / dispose` unchanged.
