Orchestrator's live record. Read this first after any compaction or handoff.

## Plan

Build order is four waves. Every piece goes builder → critic (blind, from screenshots / test runs / bot results) and merges only at ≥ 8/10. Agents never run git; the orchestrator commits after each milestone. Design contracts are in `DECISIONS.md` (§0 architecture and directory ownership, §6–7 binding zone ids).

Note: the Agent tool has no per-call `effort` parameter; `builder` and `critic` carry `effort: high` in their definitions and `.claude/settings.json` sets it globally.
